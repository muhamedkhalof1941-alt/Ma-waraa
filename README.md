# 🔴 ما وراء - نظام إدارة الأخبار والتحديثات

نظام متكامل لإدارة الأخبار وإعادة صياغتها بشكل محايد وتام.

## المميزات

✅ **لوحة تحكم ويب** - إدارة سهلة وسريعة
✅ **إعادة صياغة محايدة** - تحويل الأخبار المنحازة إلى محايدة
✅ **إدارة المصادر** - متابعة 4 قنوات تيليجرام
✅ **بوت تيليجرام** - نشر الأخبار تلقائياً
✅ **نظام الأعلام** - عرض أعلام الدول المتعلقة بالخبر

2. اذهب إلى Render.com
3. اختر "New Web Service"
4. اربط مع GitHub
5. اختر الـ repository
6. اضغط Deploy
